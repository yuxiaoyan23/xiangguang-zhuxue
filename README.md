# 向光·助学

面向高中、中职、大学新生、本专科与研究生的公益资助政策导航，包含国家及南京工业大学奖助信息、官方资料库、筛选对比、准备清单和本地资料检索问答。

## 发布

网站为静态页面，无需模型 API 或服务器程序。在 Settings → Pages 选择 Deploy from a branch，选择 main 和 /(root)，保存后由 GitHub Pages 托管。

网站预期地址（启用并成功发布后生效）：https://yuxiaoyan23.github.io/xiangguang-zhuxue/

## 内容与能力

收录资料人工核对至 2026-10-15，不自动同步。具体办理与评审以官方为准。问答为本地规则和关键词检索，未接入大模型或人工值班。本网站为学生公益宣传作品，非政府及学校官方申报平台。
